# A Museum Made For You — Combined Version

This build combines the Claude and GPT versions page-by-page according to the requested implementation map.

Flow:
1. Opening — GPT
2. Exhibit 01 / The Subject — Claude heading/title treatment + GPT gallery
3. Exhibit 02 / The Little Things — GPT
4. Exhibit 03 / Note Galaxy intro — GPT
5. Note Galaxy stars/notes — Claude presentation and note content; 5-note Continue is non-blocking, 20/20 is the completion state
6. Things We Haven't Experienced Yet — GPT layout/modal/visual system with Claude text/statuses
7. Archive — Claude implementation
8. Our Story — GPT implementation with aligned actions
9. Final — Claude implementation

The former game/interactive-installation page has been removed from the DOM, navigation, keyboard progression, and active JavaScript.

Image paths/placeholders remain under `assets/images/` and are intended for your own photos.
